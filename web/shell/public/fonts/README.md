# Bundled terminal fonts

woff2 webfonts served at `/fonts/*` and loaded on demand by the
terminal font picker (`web/lib/src/terminal.tsx`, `TERM_FONTS`).

Both are licensed under the SIL Open Font License 1.1 (see the
`*-LICENSE.txt` files). Latin subset, regular (400) + bold (700).

- **JetBrains Mono** — https://github.com/JetBrains/JetBrainsMono
- **Fira Code** — https://github.com/tonsky/FiraCode

Sourced via the Fontsource CDN (`cdn.jsdelivr.net/fontsource/fonts`).
To refresh, re-download `latin-400-normal.woff2` /
`latin-700-normal.woff2` for each family.
