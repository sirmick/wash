# Tasks

This is a small Go module. Do all three tasks, then stop.

1. `Clamp` in `clamp.go` is wrong: fix it so `clamp_test.go` passes.
2. Implement `Slug` in `slug.go` as its comment describes.
3. Implement `TopWords` in `words.go` as its comment describes.

Rules:

- Do not change any `_test.go` file. You may add new test files.
- Run `go test ./...` and make sure it passes before you finish.
- When done, write `CHANGES.md` with exactly three lines, one per task, each
  starting with the task number and a colon, e.g. `1: fixed the lower bound`.
- Finish with one short sentence saying you are done.
